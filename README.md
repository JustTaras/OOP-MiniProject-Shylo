# VetClinic Management System

Консольний додаток на C# для управління записами на прийом до ветеринара.

## 🚀 Швидкий старт

### Встановлення

```bash
dotnet restore
dotnet build
```

### Запуск

```bash
# Консольний додаток
dotnet run --project src/VetClinic.Console
```

## 📋 Основні функції

- Запис на прийом до ветеринара
- Перегляд записів (всі, за твариною, за ветеринаром)
- Управління власниками тварин та ветеринарами
- Контроль статусу запису
