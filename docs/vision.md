# Vet Clinic Management System

## Опис проблеми

Ветеринарні клініки щодня працюють з великою кількістю клієнтів, тварин та записів на прийом. 
Зберігання цієї інформації у паперовому вигляді або в неструктурованих таблицях ускладнює пошук даних, 
контроль записів та ведення історії відвідувань.

Застосунок **Vet Clinic Management System** призначений для автоматизації роботи ветеринарної клініки.
Система дозволяє реєструвати власників тварин, додавати інформацію про тварин та створювати записи на прийом.

## Цільові користувачі

- Адміністратор ветеринарної клініки
- Реєстратор
- Ветеринарний лікар

## Основні сценарії використання

1. Реєстрація нового власника тварини.
2. Додавання нової тварини до системи.
3. Створення запису тварини на прийом до ветеринара.
4. Перегляд списку всіх записів на прийом.
5. Перегляд інформації про власника та його тварин.

## Нефункціональні вимоги

1. Код повинен бути структурованим та читабельним.
2. Архітектура повинна підтримувати легке розширення функціоналу.
3. Основна бізнес-логіка повинна покриватися юніт-тестами.
4. Система повинна коректно обробляти помилки введення.
5. Застосунок має працювати без зовнішньої бази даних на першій ітерації.

## Обмеження першої ітерації (Lab 34)

- Дані зберігаються лише в оперативній пам’яті.
- Графічний інтерфейс користувача не реалізується.
- Авторизація користувачів не реалізується.
- Медична історія тварин реалізується лише як заглушка.
- Збереження даних у файл або базу даних буде додано в наступних лабораторних роботах.
