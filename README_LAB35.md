# VetClinic - Система управління ветеринарною клініцею

Профайлована система на C# .NET 10.0 для управління операціями ветеринарної клініки з архітектурою "чистого коду".

## ✨ Основні можливості

### Ітерація 1 (Lab 34) - Фундамент
- ✅ Доменні моделі (Власник, Тварина, Ветеринар, Запис на прийом)
- ✅ Запис на прийом до ветеринара з валідацією
- ✅ Контроль конфліктів (доступність ветеринара)
- ✅ Консольний інтерфейс з 5 меню-опціями
- ✅ Юніт-тести з покриттям інваріантів доменних сутностей

### Ітерація 2 (Lab 35) - Бізнес-логіка та збереження даних
- ✅ **Медичні записи**: Відслідковування діагнозів та лікування для завершених записів
- ✅ **Збереження даних**: JSON-базоване збереження файлів з асинхронними операціями
- ✅ **LINQ аналітика**: 5 складних запитів для статистики та звітування клініки
- ✅ **Паттерни дизайну**: Стратегічний патерн для розширяємого оцінювання тяжкості діагнозу
- ✅ **Розширений інтерфейс**: 9 меню-опцій, включаючи аналітику та збереження даних
- ✅ **Тестове покриття**: 21 комплексний юніт-тест

## 🆕 Нові можливості у Ітерації 2

### Управління медичними записами
```csharp
// Створити медичний запис для завершеного запису на прийом
var result = medicalRecordService.CreateMedicalRecord(
    recordId, appointmentId, pet, 
    "Гостра інфекція", 
    "Антибіотики + відпочинок 7 днів"
);

// Переглянути медичну історію тварини
var history = medicalRecordService.GetPetMedicalHistory(pet);
```

### Паттерн Стратегія для оцінювання діагнозу
```csharp
// Розширяємі оціночні модулі
IDiagnosisSeverityScorer scorer = new KeywordBasedSeverityScorer();
scorer.SetSeverityScorer(new LengthBasedSeverityScorer()); // Заміна під час виконання

int score = scorer.CalculateSeverityScore("перелом");     // Повертає 80-90
string level = scorer.GetSeverityLevel(score);             // "High", "Medium", "Low"
```

### LINQ запити для аналітики
```csharp
// Статистика ветеринара з агрегацією
var stats = analyticsService.GetVeterinarianStatistics(vet);
// → Всього записів, завершених, скасованих, майбутніх, 
//   середня кількість на місяць, найчастіші діагнози

// Багатокритеріальний пошук запитів
var results = analyticsService.SearchAppointments(
    ownerName: "Іван", petName: "Мурзик", 
    status: AppointmentStatus.Scheduled,
    fromDate: DateTime.Now, toDate: DateTime.Now.AddDays(30)
);

// Статистика клініки
var clinicStats = analyticsService.GetClinicStatistics();
// → Рівень завершення, скасування, найактивніші ветеринари, тварини, тощо

// Медичний профіль тварини
var profile = analyticsService.GetPetMedicalProfile(pet);
// → Унікальні діагнози, частота, медичні записи
```

### JSON збереження даних
```csharp
// Автоматичне збереження файлів
await repository.InitializeAsync();        // Завантажити з файлу
await repository.PersistAsync();            // Зберегти у файл

// Дані зберігаються у: %APPDATA%\VetClinic\clinic_data.json
```

## 🔧 Стек технологій

- **Мова**: C# 12.0
- **Фреймворк**: .NET 10.0
- **Архітектура**: Clean Architecture з багатошаровим дизайном
- **Паттерни**: Repository, Strategy, Result
- **Збереження**: JSON файли (System.Text.Json)
- **Тестування**: xUnit
- **Асинхронність**: Task-based async/await

## 💡 Ключові рішення щодо дизайну

1. **Repository Pattern**: Абстракція для доступу до даних, дозволяє тестування та заміну збереження
2. **Strategy Pattern**: Розширяємі оціночні модулі без зміни існуючого коду
3. **DTOs для збереження**: Відокремлення JSON схеми від доменних моделей
4. **Async/Await**: Неблокуючі операції для I/O та майбутної масштабованості
5. **Result<T>**: Функціональна обробка помилок замість винятків у сервісному шарі
6. **In-Memory Storage**: Швидкий, тестований фундамент з асинхронним шаром збереження файлів
